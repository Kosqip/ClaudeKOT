# Запуск на своём компьютере и что проверить

## 1. Запуск (Windows)

Один раз установить: [Node.js 22 или новее](https://nodejs.org/) и [Git](https://git-scm.com/download/win). Claude Code должен быть установлен и авторизован как обычно (в PowerShell команда `claude` запускается и не просит войти).

Открыть PowerShell и выполнить по очереди:

```bash
git clone https://github.com/Kosqip/ClaudeKOT.git
```

```bash
cd ClaudeKOT
```

```bash
npm install
```

```bash
npm start
```

Первая сборка идёт пару минут. Когда появится строка `Server URL: http://localhost:3001`, открыть этот адрес в браузере, создать локальную учётную запись и выбрать папку проекта. **Для проверок выберите пустую тестовую папку, а не рабочий проект.**

Остановить: `Ctrl+C` в окне PowerShell.

Обновить после новых правок:

```bash
git pull
```

```bash
npm install
```

```bash
npm start
```

Ключ OpenRouter (нужен для роли «рутина» и Custom API): скопировать файл `.env.example` в `.env`, вписать строку `OPENROUTER_API_KEY=sk-or-...`, перезапустить `npm start`.

Если `npm install` падает с ошибкой про `better-sqlite3` или `node-gyp`: проверить, что Node.js именно 22+, и повторить. Если не помогло — открыть Claude Code в папке ClaudeKOT и показать ему текст ошибки.

## 2. Что проверить (по порядку, от простого)

Отмечайте, что сработало. Если что-то не так — **Настройки → О программе → «Сохранить отчёт»** сразу после сбоя и отдать файл Claude.

### А. Основа
- [ ] Приложение открывается, вход работает, название везде «ClaudeKOT».
- [ ] Обычный чат с Claude: отправить «привет», приходит ответ.
- [ ] Под полем ввода виден индикатор использования лимита Claude (появляется после первого ответа).
- [ ] Настройки → О программе → «Сохранить отчёт»: скачивается текстовый файл, в нём Claude отмечен как `installed, signed in`.

### Б. Custom API (нужен ключ OpenRouter)
- [ ] Новый чат с бэкендом «Custom API», бесплатная модель: приходит ответ.
- [ ] Настройки → Агенты → «Выбор поставщика в OpenRouter»: переключается и сохраняется.

### В. Оркестратор
Настройки → Агенты → «Роли бэкендов»: Claude — «Оркестратор», Custom API — «Рутина».
- [ ] В чате с Claude кнопка «Оркестратор». Задача-пример: «Создай файл notes.md с тремя идеями названий для кота, потом проверь его на опечатки». Запустить.
- [ ] Появляется план, подзадачи по очереди становятся «готово», в конце — итог. Файл действительно создан в тестовой папке.
- [ ] Подзадача «только чтение» ничего не меняет в папке.
- [ ] Запустить задачу и нажать «Остановить» посреди работы: всё останавливается за несколько секунд, статус «Остановлено».
- [ ] Запустить задачу и посреди работы закрыть сервер (`Ctrl+C`), снова `npm start`: задача показана «На паузе», кнопка «Продолжить сейчас» доделывает оставшееся.

### Г. Лимиты (получится проверить только когда лимит Claude реально близко или кончился)
- [ ] При приближении к порогу (Настройки → Агенты, по умолчанию 90%) после ответа появляется предложение перенести сессию.
- [ ] Когда Claude отказал по лимиту в обычном чате: сессия сама переезжает на запасной бэкенд.
- [ ] Когда Claude отказал по лимиту внутри задачи оркестратора: задача встаёт «На паузе» с временем продолжения (или подзадача уходит другому бэкенду). **Это самое важное и ни разу не проверенное вживую место — обязательно сохранить отчёт диагностики в этот момент.**

### Д. Остальное
- [ ] «По типу задачи» (роутер): текст со словом «рутина»/простая задача уходит в Custom API.
- [ ] «В несколько сессий» (микс): одна задача уходит в две сессии.
- [ ] Настройки → Плагины: установка шаблонного плагина «Статистика проекта» из списка (это сторонний код — по желанию).
